# Consulta de CNPJs 2.0

## Publicação
1. Crie um repositório GitHub NOVO, por exemplo `consulta-cnpj-2`.
2. Envie `app.py` e `requirements.txt` para a raiz desse repositório.
3. No Streamlit Community Cloud, crie um app novo e conecte esse repositório.
4. Escolha `app.py` como arquivo principal e clique em Deploy.

O app aceita até 10.000 CNPJs únicos por lote. Isso não garante que a API responda a todos sem limitações.
